Marie Zendee — production-ready portfolio V18

Deploy the contents of this folder at the repository root.

Production checklist:
1. Keep/update assets/PATALINGHUG, MARIE ZENDEE CV 2026.pdf with the latest résumé.
2. Confirm berry-zendee.vercel.app is the final canonical domain. If the domain changes, update canonical/Open Graph URLs in index.html.
3. Test once on a real iPhone/Safari and one Windows/Chrome device after deployment.
4. Remove the old iPhone Home Screen shortcut and add it again if Safari has cached an older icon.
5. The first visit uses the full intro; repeat visits in the same browser session use a shorter intro.
6. Audio is user-triggered by browser policy. The sound control in the navigation enables/disables the portfolio music.
7. 404.html is included for a branded fallback page.
8. WebP responsive image variants are included to reduce transfer size and improve mobile performance.
